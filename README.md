Exercises for MAT2007, written in R. The files for each week start with the
week number.

## Week 5 homework: plotting the solar cycle

| File | What it is |
|------|------------|
| `week5homework.R` | Code for Homework 1 and Homework 2 |
| `week5_homework1_solar_cycle.png` | Homework 1: the solar cycle as a function of time, and the average number of sunspots per cycle with its statistical uncertainty |
| `week5_homework2_systematic_uncertainty.png` | Homework 2: the same averages with the statistical uncertainty and the total uncertainty (statistical and 10% systematic) |
| `solar_cycle_data.txt` | The pseudodata from the Week 4 homework, which the Week 5 code reads |
| `week4homeworkUPDATED.R` | The Week 4 homework code that generates `solar_cycle_data.txt` |

To make the plots, run `week5homework.R` from this folder, for example with
`source("week5homework.R")` in R. It reads `solar_cycle_data.txt` and saves
the two PNG files.
